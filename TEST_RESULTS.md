## Running these yourself

```bash

scripts/run_all_tests.sh python web   # a subset
```

Two environment traps the script handles for you, because neither error names its real cause:

- **`cargo test` in `rulemind-core-rs` needs `--no-default-features`.** The default `python` feature pulls pyo3 `extension-module`, which deliberately does not link libpython, so a plain `cargo test` dies at link time on a missing `_Py_TrueStruct`.
- **The Postgres lane needs `RULEMIND_TEST_PG_SCHEMA_PER_PATH=1` and a `postgresql://` URL.** Without the flag, 66 modules construct `Storage(path=…)` and silently re-run SQLite. With `postgresql+psycopg://` every module fails to import (`No module named 'psycopg'`) because requirements pins psycopg**2** — ~153 loader errors that look like a broken virtualenv.
